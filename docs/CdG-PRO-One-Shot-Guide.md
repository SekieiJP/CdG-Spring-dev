# PRO一発勝負：14の判断指針

リセマラなしの固定自動方略V1は、最初の1,000開始を全採用して**平均12.026点、中央値12点、8点以下26回（2.6%）、S以上69.0%**だった。更新された目標「平均12以上・8点以下3%未満」を満たす。3%未満なので1,000開始では29回以内が必要で、30回は含まない。

以下は**同じ方略の判断軸を14個に整理した人向けの説明**。自動方略は公開情報から複数の仮想将来を比較するため、この指針だけで全局面の選択を完全再現することはできない。人がこの指針で同じ成績になるか、簡略化した自動方略が同じ条件を満たすかは未検証である。ゲーム内の助言・光る取得候補は短時間の固定数式であり、研究用方略の将来試行を実行しない。

1. **一発勝負は最初の候補から完走する。** 初期リセットは使わない。ゲーム内で回数が限られた研修リフレッシュは使ってよい。
2. **Sは4項目の合計点で狙う。** 満足15・経理15で退塾0を目指し、体験50・入塾32、体験40・入塾40、体験40・入塾32・満足25など、手持ちに近い12点経路を選ぶ。
3. **今の数値だけでなく、残り何回使えるかを見る。** 所有枚数、ドロー、置き場、コストを一緒に確認する。取得した札を毎ターン使えるとは数えない。
4. **最初の2枚は組み合わせで選ぶ。** 体験・入塾・回復の補完と、並行や次の手数を増やす効果を比較する。単体の大きさやレア度だけで決めない。
5. **序盤の手数は、置き切れる構成と組にする。** 情熱で多く引けても通常の3枠が詰まれば余る。並行札や配置先の分散を混ぜ、疲労で次のドローが減る分も見る。
6. **条件付き札は、条件を作る札と一緒に取る。** たとえば「卒業生からの手紙」は満足15が必要。「事務リーダー1日派遣」は経理14への設定で、単独では経理15を保証しない。
7. **研修リフレッシュは、今の候補と残す価値を比べる。** 弱い提示を交換できるが、先で必須札が出ると決めつけない。必要役を補える提示を、レア度だけで流さない。
8. **中盤以降は、近い得点の節目を埋める。** 体験40→50、入退差26→32→40→48、満足25→35などを見る。入塾は体験を超えられず、経理15を超えた余剰は直接加点されない。
9. **発想の追加取得は、取らない選択も比較する。** 弱い札を増やすと強い札を引く割合が下がる。必要な役割や手数を増やさない候補は辞退も考える。
10. **削除順をカード名で固定しない。** 弱い基本札から見直しつつ、消した後に引く札・置く札を考える。「基本5枚がなくなるまで他を消さない」は採用方略ではない。
11. **不足する役割の最後の1枚は、代役を確認してから消す。** 特に満足・経理の回復、体験の供給を点検する。デッキ枚数を小さくすること自体を目的にしない。
12. **通常札を先に置き、その場所に並行札を重ねる。** 室長専用が複数ある場合は、最も必要な役割へ枠を渡す。引けた札を全部置く必要はない。
13. **解決順は室長→講師→事務。** 各札の直前にコストを払えるよう回復を先にし、体験を上げてから入塾を伸ばす。後の事務の回復は、先に解決する室長の支払いに使えない。
14. **最終ターンは、実際の得点で選ぶ。** 次の情熱・発想・整理や疲労には次ターンの価値がない。条件切れとコストを確認し、既に届いている得点を不要な配置で失わない。

## 15点を繰り返し狙う場合

一発勝負と区別し、このカテゴリだけは最初の2枚を選び直すリセマラを利用できる。序盤から働く情熱・発想・並行を揃え、体験50・入退差48・満足25、または体験50・入退差40・満足35などの同時成立を狙う。回復を捨てて大きな札を集めるだけでは、退塾の減点で届かなくなる。

V1の同じ最初の1,000開始では15点以上31回、全2,000開始では56回だった。これはリセマラなしのV1の記述であり、別の後続方略を使った[リセマラ研究](CdG-PRO-Reroll-Guide.md)の成功率と、そのまま比較しない。リセマラに要する時間や途中打切りの最適基準は測定していない。
