# 結果履歴とスコア送信（T07）

## 保存するもの

`ResultRepository`は`cdg_results_v1`に、結果履歴と未送信の確定ペイロードをまとめて保存する。ゲーム途中の`cdg_save_data`1件、直前の詳細ログ`cdg_last_play_record`とは別である。

- 履歴は直近50ゲーム。得点、主要パラメータ、最終デッキ、難易度・モード、コード／ルール／カード／ランクの版、開始・完了時刻と結果IDを保存する。
- 未送信は直近5ゲームの範囲に限定する。新たな結果を確定した際、6ゲーム以上前の結果は待機から外し、履歴には残す。後のゲームが送信済みでも古い未送信を保持し続けない。
- カード・ランク・ルール・難易度・モードが同じ過去の結果だけを「前回」と比較する。古い環境の履歴自体は削除しない。
- 結果IDには保存・再開にも使う`runId`を用いる。同じゲームの結果を再表示しても、二重保存・再送信しない。
- 保存容量などで端末の永続保存に失敗した場合は、画面内に結果を保持して状況を表示する。古い永続データで新しい結果を上書きしない。再読み込みで画面内の未保存分が失われる可能性がある。

タイトルの「履歴」、結果画面の「プレイ履歴」、設定の「プレイ履歴」から確認できる。各結果を開くと、版・得点・パラメータ・最終デッキを見返せる。全操作ログは履歴へ複製しない。

## 再プレイと通信

`ResultController`が完了時の結果を保存し、`SubmissionQueue`がそのコピーを送信する。新たなゲームの状態・デッキを送信処理から参照しない。結果を保存した後は送信中でも再プレイできる。送信済み・保留・待機上限からの除外を結果画面と履歴で表示する。

1回の通信はfetchとJSON応答を合わせて8秒で打ち切り、送信機会ごとに最大3回、間隔2秒で試す。失敗した結果は直近5ゲームの範囲で保持する。起動時、オンラインへの復帰、新たな結果確定、履歴の再送ボタンで再試行する。処理中に新たな結果を追加しても、同じ処理内で失敗結果の試行上限を増やさない。

再送では結果ID・完了時刻・最終デッキなどを変更しない。送信中の古い結果が待機対象から外れた場合はクライアントで中断する。中断してもサーバーがすでに受領している可能性があるため、除外を「未受信が確定した」とは扱わない。以前の結果への応答で新しい結果の送信表示を上書きしない。

## GAS側の変更

`gas/scoreReceiver.gs`の変更はコードとローカル検証までで、実際のWeb Appへは未反映。

ScriptLock内で結果IDの検索と書き込みを行い、SpreadsheetApp.flushで書き込みを確認してから受領済みとする。Cacheが失効・利用不能でも、シートの結果ID列から重複を検出する。重複した再送は`status: ok`と`duplicate: true`を返す。書き込み失敗をCacheに記録して再試行を塞がない。

既存列・行を保持して「結果ID」「ルールバージョン」「カードバージョン」「ランクバージョン」を追加する。結果IDがない旧クライアントには不変な日時・利用者・得点から安定したIDを付ける。既存のIDを持たない過去行はそのまま残し、過去全行のIDを推定する移行は行わない。

追加難易度は登録と同じID形式で受け付ける。カード種類数と送信する所有枚数は分け、最終デッキ・削除履歴は各200枚、ペイロードは32,000文字を技術上限とする。ゲームのカードプール上限や得点ルールは変更しない。

公開反映時は、GASの新しい受信コードを既存デプロイへ反映してからクライアント0053を公開する。同じ送信URLを維持する。実環境では少数の識別可能な確認結果を用い、書き込み・同じ結果の再送・応答だけを失った再送で1行になることを確認する。通常の自動テストはテスト用応答を使い、公開シートへ記録しない。

実装で参照したAPI：[TextFinder](https://developers.google.com/apps-script/reference/spreadsheet/text-finder)、[Lock](https://developers.google.com/apps-script/reference/lock/lock)、[Cache](https://developers.google.com/apps-script/reference/cache/cache)。

## 検証

単体テストで50件／直近5ゲームの独立管理、保存失敗後の保持、環境別の前回比較、ペイロードの不変性、fetch・JSONの停止、再試行、通信回復、待機から除外された送信の中断を確認する。GASはローカルの代替シート・Cache・ロックで、重複・Cache失効・書き込み／flush失敗・旧形式・列の追加を確認する。

ブラウザでは送信中の次ゲーム開始、保留の再読み込み再送、終了状態からの復帰と再描画の重複防止、前ゲームの応答と新しい結果表示の分離、履歴の閲覧を検証する。実GASの公開環境・実機での通信復帰は別途確認する。
