# PRO・リセマラなし平均12.5点とカード評価の研究

2026-10-04。ユーザーの目標は、リセマラなしで平均スコア12.5を達成する取得・配置・削除方略を完成させ、低得点の救済と中高得点の増加のどちらが必要かも検討し、その方略のもとで個別カードの有効な場面、取得時期、相性、スコアへの貢献を評価すること。旧比較の `codex/pro-strategy-research` は2815309で保持し、短い先読みは `codex/pro-horizon-research`、配置候補・回復役保護・新固定評価は `codex/pro-action-research`、初回共通評価は `codex/pro-opening-research` で比較した。これらは完走済みで、削除・成長比較は `codex/pro-growth-research`、新しい入塾重視比較は `codex/pro-enrollment-research` で並行して行う。ゲーム本体のルール・カード・推薦表示は変更しない。

**一発勝負は最初の候補から1ゲームを完走し、初期・途中のリセマラを使わない。リセマラを利用できるのは15点狙いのみ。本目標は一発勝負なので、開始の選別・途中打ち切り・リセットを混ぜない。ゲーム内の回数制限付き研修リフレッシュは利用できる。**

## 到達条件

- 初回提示から全ゲームを完走する。初期・途中のゲームリセットをしない。ゲーム内の回数制限付き研修リフレッシュは利用可。
- 各傾向比較は最低250個の異なるシード。方略選択・調整に使わない独立した1000シード以上で、実ゲームの平均12.5点以上を確認する。平均の95%区間・下位10%・8点未満・退塾数を併記し、観測平均と推定の不確実性を区別する。
- 全開始の得点分布を分解し、低得点の救済だけで平均目標に届くか、中高得点を増やす必要があるかを検討する。事後的な得点の置換は実現可能な改善として扱わない。
- 方略の完成を確認してから、その同じ版で個別カードを評価する。保有と好成績の共起、実際の解決量、取得候補の強制選択を比べる局面試験を区別する。カード単体に因果効果があるという表現は対照比較の範囲に限る。
- 人向け判断例は、その判断を採用した方略の好成績と実際の公開情報・操作記録に基づく。成功例1件を一般的な優位の証明には使わない。

## 既存方略の問題を確かめる

前回の独立1000シードで、エンジン重視の方略は平均11.020点。退塾なし798ゲームの平均は11.749点、退塾あり202ゲームは8.139点、8点未満56ゲームは平均2.196点だった。回復だけで12.5に届くとは限らず、体験・入塾・満足の加点と両立する必要がある。

## 新しいアプローチ

従来の平均ドロー率による数式投影に加え、ブラウザ内で公開デッキから仮の手札・研修候補を独立に生成し、配置競合、コスト、条件、情熱・疲労、削除を経て最終得点を評価する。実際の未来の山札・研修順・乱数状態・ゲームシードは判断に渡さない。仮想将来を候補間で共通に使い、平均得点と大失敗の頻度を比較する。これは分析用であり、短時間の数式を使うゲーム本体の取得アシストには接続しない。

1. 既存方略を同じ新規シードで再評価する。
2. 取得だけ、全操作、低得点の追加抑制を分けて各250シード以上で検証する。
3. 過剰な回復、配置競合、未来の成長予測、圧縮の失敗を実際のログから診断し、公開情報で再現できる改善を行う。
4. 有望な版を固定し、独立検証する。未達なら目標を維持して研究を続ける。
5. 達成版で全カードの使用実績と局面別対照試験を蓄積し、人向けレポートをまとめる。

個別ログは `solver/local-runs/pro-mean125/`、集計は `solver/local-evaluation/pro-mean125/` に保存する。ログは可逆圧縮し、設定・ハッシュ・集計をドキュメントとともに研究ブランチへ残す。

## 学習済み状態評価の検証

過去3,000個の異なる開始シードのリセマラなし完走から、取得後・配置後・会議後の公開状態73,261件を抽出する。1ゲームの総学習重みを1とし、発想研修の多いゲームを過剰に重視しない。別250シード6,071状態で予測誤差を確認する。教師ラベルとして過去の最終得点を使うが、新規ゲームの判断には最終得点・開始シード・乱数・未来順序を渡さない。

特徴量作成と学習はブラウザ内。状態、トークン、カードNoごとの所有枚数、配置競合を含む固定式投影、公開済み提示・恒久除外を特徴とする。学習した小さな木の固定回数計算で取得・配置・削除を評価する。過去の方略下での予測であるため、他の操作に切り替えても同じ精度とは仮定しない。初めて使う250開始シードで、取得のみ、配置のみ、削除のみ、全操作、旧式との混合率を分けて比較する。最終配置は学習予測に関係なく公式得点を優先する。

実行順：`pro-value-dataset.mjs` で記録抽出、`pro-value-train.mjs` でブラウザ学習、`pro-mean125-study.mjs` で本体実エンジンの比較、`pro-mean125-metrics.mjs` で集計。モデルと教師データは個別記録と同じローカル保管。モデルSHA、本体・カード・ランク表SHAを一致検査し、研究集計に版を残す。

現在の[得点分布の診断](CdG-PRO-Score-Distribution.md)では、8点未満だけの救済では不足し、10〜12点のゲームを伸ばす必要がある。大失敗の件数を併記しながら、取得・配置に加え削除後の成長と回転を調べる。
