# PRO・中得点を伸ばす削除と先読みの比較

2026-10-04。作業ブランチは `codex/pro-growth-research`。完走した初回評価研究の35836d2から分け、元の研究ブランチを保持した。最新目標はリセマラなし平均12.5点の方略完成、低得点救済と高得点化の寄与の検討、達成した同じ版での全カード評価。

## 仮説

[全開始の得点分布](CdG-PRO-Score-Distribution.md)では、8点未満の救済だけでは平均目標に不足する。10〜12点の回を13〜14点へ伸ばすため、取得・配置で選んだ成長役とデッキ圧縮の関係を調べる。新しい学習モデルや初回表では明確な改善が見られなかったので、旧V1と両方2ターン先読みを比較基準として残す。

現方式の会議での削除は、固定式で投影した成長を比較して選ぶ。候補の削除と保持を、公開情報による仮のドロー・取得・配置を経た評価で比べる既存の削除先読みへ切り替える。削除する場合に成長を失う局面、圧縮で強い札を引ける局面を区別できるかを検証する。もう一つは、取得・配置の実際に展開する範囲を2→3ターンへ延ばし、境界を越える成長や発想取得を少し先まで評価すること。

| 条件 | 実際の取得・配置 | 実際の削除 |
| --- | --- | --- |
| baseline | 2ターン先読み | 従来の固定投影・aggressive |
| delete-rollout | 2ターン先読み | 保持と各削除を2ターン先読みで比較 |
| horizon3 | 3ターン先読み | 従来の固定投影・aggressive |
| horizon3-delete-rollout | 3ターン先読み | 保持と各削除を3ターン先読みで比較 |

実際の削除先読みは、各1枚の候補を順に評価し、保持との差が0.005より大きい場合だけ削除する既存方式。複数枚の全組み合わせの最適化ではない。学習評価へ渡るまでの仮想将来の配置は既存baseline、削除はaggressiveなので、実際の後続方略と完全に同じとは仮定しない。短い先読みと後続方略の近似を含む実成績として確認する。

## 固定条件と到達の判断

新しい同じ250開始シードを全4条件で採用する。初期候補や途中の成績で選別・打ち切り・リセットをせず、回数制限付きのゲーム内研修リフレッシュのみ利用する。判断・仮想操作・実ゲーム操作はブラウザ内。実ゲームのシード・未来順序・結果を判断へ渡さない。

仮想将来8通り、V1深さ3、混合0.005、末端混合0.002、実配置探索128、仮想配置64、保持下限4、研修リフレッシュ費用0.12・序盤残し0.25をそろえる。初回共通表・新回復役保護・候補分散は使わない。11ファイルSHAと本体・カード・得点表・モデルSHAを記録し、試験中に変更しない。ゲーム本体・公開推薦・MASTERは変更しない。

平均と名目95%区間、中央値、13点以上、S+以上、15点以上、8点未満、退塾、取得・ドロー・配置・削除数を集計する。基準からの得点帯の移動を全250開始で対応比較し、低得点救済と中高得点への上積みを区別する。発想や圧縮の回数だけで強さを主張しない。研究用ブラウザは2つまで同時に動かす。

有望な版を固定し、選択・調整に使わない1000シード以上で実平均12.5点を検証した後、その版で個別カードを評価する。開発250の最高値と少数の接続確認を達成証明としない。
