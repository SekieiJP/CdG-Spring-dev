## 統合する機能

`codex/ahiru-fresh-advice`には共通改修T02〜T08、FRESH取得推薦、PRO取得推薦が既に含まれることを祖先照合した。取得・削除でのPRO/FRESH助言、パラメータ直下の44pxの顔、赤/黄/緑、25文字以内のインライン吹き出し、3秒で補正なしへ戻る読み込みを統合する。設定の取得アシスト既定オンと5秒後の淡い強調を維持する。

PROの取得候補には同じ助言用の公開デッキ投影を適用する。不足/余剰からの伸長先を補い、Sへの最小経路の不足量を広げない候補がある場合に優先する。その群内は既存のS+取得式の順位を維持し、該当候補がなければ元の推薦を使う。補正の読み込み後も提示時刻は変更せず、5秒の期限で表示する。FRESHの取得数式と重みは変えない。

保存済み全2,000開始の18,770取得局面で静的に照合し、1,582局面の推薦が変わった。Sへの距離は固定式の見積もりであり、実際の将来の保証ではない。公開版と同じコードでの再照合でも全件数が一致し、研究用MacのChromiumで計算p95約0.8ms、最大8.4ms。[最終コードの整合性診断](../solver/research-results/ahiru-advice-20261103/pro-assist-consistency-final.json)。同じ2,000開始の再利用で、新しい完走ゲームの成績測定や介入効果の証明ではない。Safari実機の性能とも区別する。
