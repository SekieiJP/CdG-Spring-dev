## 1. 担当範囲と決定事項

このスレッドでは、ユーザー指定のT08以降に当たるMASTER固有の仕様・取得方法・カードバランスを相談する。[共通改修の作業計画](CdG-Shared-Work-Plan.md)では、これらをM08・M09・M10、難易度追加の共通基盤をT08と表記している。共通基盤、全難易度の評価・UI・再プレイ改善は別スレッドの担当とする。

共通側のチェックアウトを切り替えず、MASTER用の独立したworktreeで文書を更新する。実装の着手時期・追加カードの採用は、仕様相談で決める。

### ユーザーが決定した方針

- PROを土台に新難易度MASTERを制作する。構築の幅を第一にし、狙ったカード・コンボの作成を優先する。
- 契約講師、膨張編成、デメリット回避の組み合わせ、山札からの選択ドローを成立させる。
- 既存のPROまでのカードをデッキプールに維持し、新カードを最大25種類程度追加する。MRも新カードの追加数に含める。旧52種類制限と入れ替え前提は撤回する。
- カード取得選択は一度に3択以内、配置先は4択以内。配置先が決まれば効果は一意に定まり、効果モードの宣言は要求しない。
- 序盤に役立つカードと、終盤にコンボで強い効果を出すカードを両方収録する。
- 発動条件・リスクに応じて、各パラメータがPROより0〜35%程度高く出る数値設計を目指す。
- 望んだ方針の構築成立率は約70%。核が全く機能しない事態への対策があれば下振れは許容する。
- 核となるカードのレア度はMR（マスターレア）。MRは契約不可。
- MASTERのR・SRは全札に契約時の効果を持たせる。SSRは契約不可。
- 「契約可」という表記は設けない。契約効果が記載されていること自体が契約できる目印になる。
- 同じレア度内で契約効果が重複してもよい。SRはRより条件が狭い、またはデメリットを持つ代わりに、比較的大きいバフを持つ。
- 効果の発動順は、契約講師 → 室長 → 講師 → 事務。
- 選択ドローの名称は「想起」。カードが定める条件・枚数の対象を発動時に山札から探して引き、保留し、次ターンの最初に手札へ加える。
- 想起はカード取得選択ではないため択数制限を適用しない。ただし、カードごとの対象条件で選択肢を絞る。
- ルール・カードの名前・効果に、塾運営の物語上の理由を持たせる。
- スマホ縦画面の圧縮表示、長押し詳細と目印、速度据え置きでのタップスキップ、カード評価の見える化は全難易度共通に適用する。
- 今後の改善は作業ブランチで実施する。

### 今回の指導コスト案と、未確定の境界

ユーザー案である「Rの新規配置・交代は講師または室長、SRは室長が1ターン仕事を休んで教える」を基本案として採用推奨する。指導役の自動判定、契約枠数、初回発動、交代した旧札の戻し先などの細部は下記の提案であり、まだ確定していない。

MRの契約不可と想起の択数制限なしは、2026-10-07の回答で確定した。Nの契約不可、想起を通常ドローへの追加とする方式は引き続き提案。対象0枚、支払い付き想起、保留中の削除などの境界も未確定。

以下のカード名・数値・取得方法・成立条件は提案。0〜35%と約70%は目標であり、現時点の実測値ではない。

## 2. MASTERの基本構成案

PROの8ターン、基本カード5枠、初期ステータス、室長・講師・事務、情熱・発想・整理・並行・疲労を出発点にする。契約講師を第4の配置先として追加する。保留はカードの所在であり、第5の配置先にはしない。

通常配置と契約では別の固定効果を使う。通常スタッフの配置制限は通常効果に適用し、契約配置には契約効果の条件と指導コストを適用する。たとえば通常効果に「事務のみ」とあるRも契約に配置できる。

4つの構築方針は組み合わせ可能にする。契約の補助で高リスク札を使い、想起で次の組み合わせを確保し、情熱・並行で膨張につなげる。追加の方針宣言や、ドローか得点かを選ぶ効果モードは設けない。

## 3. 契約講師：指導と継続

### 指導コストの基本案

| 新しく契約する札 | 指導のため空ける通常スタッフ | 物語上の理由 |
|---|---|---|
| R | 講師または室長の少なくとも一方 | 日常業務の手順を、実務を知る講師か室長が教える |
| SR | 室長 | 専門的な判断や教室全体への影響があり、責任者による指導が必要 |
| SSR | 契約不可 | 一時的な大施策・特別支援を、通常の継続業務にはしない |
| MR | 契約不可（決定済み） | 通常配置で構築方針を実行する核 |
| N | 契約不可を提案 | 通常業務の基本として使う |

新規配置・交代するターンの全行動を、指導に使う。契約が継続する後続ターンでは通常スタッフ3名を使える。交代コストは、旧札ではなく新しく教える札のレア度で決める。

通常スタッフに並行札1枚でも配置していれば、そのスタッフは「空いている」とは扱わない。指導中に並行を使って別の仕事もすることはできない。

### 指導役を選ばせない操作案

- Rは最終配置で講師・室長のどちらかが空いていれば契約可能。両方が空いていれば講師を指導役として表示する。
- R契約の準備後に講師へ通常札を置いた場合は、室長が空いていれば指導役を室長へ自動変更する。逆の場合も同様。両方を埋める配置は受け付けない。
- SRの新規配置・交代中は室長を指導中として表示し、通常札を置けない。先に室長に置いていた場合は、配置を取り消してから契約する。
- 行動確定までは契約・通常配置を取り消せる。契約変更を取り消したら元の契約と指導制限を復元する。
- 「講師／室長を空けて指導」「室長を空けて指導」を契約先に示す。指導役を選ぶ追加画面は作らない。

Rは通常行動2名＋契約、SRも通常行動2名＋契約で初回を進める。SRでは室長の強い行動を失うため、狭い条件・リスクに見合った効果量が必要になる。

### 継続・交代の細部案

| 項目 | 提案 |
|---|---|
| 容量 | 契約講師は1枠・1枚。並行による重ね配置はできない |
| 初回発動 | 新規契約・交代したターンから新しい契約を1回判定。条件不成立なら不発 |
| 継続 | ターンを跨いでも残り、各ターンの行動解決時に1回発動する |
| 解決順 | 契約講師 → 室長 → 講師 → 事務（決定済み） |
| 交代 | 新しい契約だけが当ターン発動する。旧札は行動確定時に山札へ戻し、当ターン再使用しない |
| おすすめ | 契約効果には通常スタッフのおすすめ行動ボーナスを付けない |
| 自主退契 | 会議の削除機会を使って契約札を除外できる案。自由な退契の可否は未確定 |
| 不発 | 条件不成立・コスト不足でも契約は残る。発動の成否と有効な増分を別々に記録する |

同じ契約札を置き続ける限り、毎ターン指導コストを払い直さない。行動確定前の仮配置では、効果・交代・山札への返却を実行しない。

室長の通常配置を条件にするSRは、新規配置・交代したターンには条件を満たせない。これは「指導の日は通常の連携業務まで回らない」という待機期間になる。その分の機会損失も測り、初回から有効なSRと区別して説明する。

### RとSRの効果設計

Rは条件が軽く、毎ターン単一パラメータ+1、疲労1軽減など、早期に導入しやすい支援を中心にする。SRは複数配置・既存パラメータ・残りターンなどの条件、または経理・満足・疲労の負担と引き換えに、+2〜4程度の合計増分や強い補助を持たせる。数値は初期案であり、トークンや想起を単純な+1と同価値には扱わない。

SRがどの構築でもRの上位互換になることを避ける。Rの安定性と指導役の融通、SRの条件が成立する場面の出力をそれぞれ評価する。全R・SRの具体案は[契約効果一覧](CdG-MASTER-Contract-Effects-Draft.md)に記録する。

条件に使う通常配置枚数・カテゴリは、行動確定時の配置で判定する。後から効果不発になった札も「配置」には含まれる。「有効に使用した枚数」を条件にする場合は別の条件として明記する。ステータス条件は契約効果の解決直前の値を使う案。

契約が先に発動するため、後続の室長・講師・事務が出す軽減で契約自身のデメリットを遡って消せない。契約の支援は後続札のリスクを支え、契約自身の負担は事前の資源や後続の回復で管理する。

### カードの所在・保存

契約札は山札・手札・通常配置とは別に保持する。所持枚数・最終所持カードには含め、通常ドロー・想起の山札検索には含めない。

個体ID、元の契約、仮の交代、当ターンの指導役、解決済み状態、補助効果の残量を保存する。通常配置がターン終了時に山札へ戻っても契約を戻さず、演出のスキップ・中断再開で再発動しない。

## 4. MRの核と取得方法

### 初回研修の案

PROの初回取得2枚を、次の2回の選択に置き換える。いずれも3択以内。

1. 固定のMR核3枚から1枚を選ぶ。
2. 選んだMRを支えるRを含む最大3候補から、もう1枚を選ぶ。

MRは「希少だから偶然引けた人だけが構築できる札」ではなく、序盤に選べる構築の核とする。初期デッキの基本札とは別に取得する。MR3案は新カード最大25種類程度の内数として提案する。

MR3種類を通常配置で使う第一案では、以下の役割にする。

| MR案 | 序盤の役割 | 終盤の役割・物語 |
|---|---|---|
| チーム編成研修 | 条件の軽い体験増分と情熱・発想で、取得とドローを始動 | 人員配置の計画を共有し、多数配置で増分を伸ばす |
| 教務分担の設計 | 条件が整わなくても入塾に寄与 | 契約との分担・リスク軽減で専門札を組み合わせる |
| 授業計画の共有 | 満足への寄与と想起で、次の行動札を用意 | 特定の支援札・完成札を繰り返しつなぐ |

具体的な通常効果は[統合カード提案](../outputs/01a0fb7b-a927-74c3-8ab7-9cb3a3ddd50a/CdG-MASTER-Card-Proposals-20261007.xlsx)に候補を記載した。採用と数値調整は相談で決める。MRは初回専用で1ゲーム1枚、選ばなかったMRは通常研修に混ぜない案。複数MRを組み合わせられる取得機会を設けるかは未確定。

### 核が機能する機会

- 最初の手札は通常ドロー1枚をMRに置き換え、手札枚数を増やさずに核を含める案。
- 条件が揃わない序盤でも、MRに低い条件の基本効果を持たせる。
- 新R「代講用授業ノート」に、山札の選んだMRまたは並行Rを最大1枚想起する案を持たせる。ただし、その時点で手札・配置・契約にある札は想起できない。特定の支援札だけが必須にならないかを測る。
- 核の取得、ドロー、配置、有効発動を別々に測定する。上限により増分0のケースも把握する。
- 完成札の保証とMRの初回保証は区別し、支援・完成札の供給で構築成立約70%を目指す。

### 支援札・完成札の供給

2ターン目のSR研修と5ターン目のSSR研修で、MRや取得済み支援札に合う候補を1枠含める案。残りは通常候補、各選択は最大3択とする。

適合は定義タグで判定し、追加の方針宣言は要求しない。候補の提示枚数と取得枚数、発想による追加取得、同名札の在庫、適合札不足、リフレッシュの扱いは実装前に詰める。プールの無制限複製は前提にしない。

カードプールの拡大で必要札の取得機会が薄くならないよう、適合候補の供給を優先して検討する。想起は取得済みの山札だけを探すため、取得の保証・選択機会と想起は別の仕組みとして評価する。

## 5. 想起：今引いて、次ターンに使う

### 決定された基本動作

1. 想起を持つカードの効果解決時に、そのカードの条件・枚数に合う対象を現在の山札から探す。
2. 対象のカード個体を直ちに山札から取り出して「保留」へ移す。
3. 当ターンの手札には加えず、保留したままターンを移行する。
4. 次ターンの最初に保留札を手札へ移す。

前案の「指名の予約だけを付け、翌ターンに対象を探す」は撤回する。想起は単なる予約数ではなく、すでに引いた実物のカードを保留する効果とする。

### 通常ドローとの関係：追加を推奨

想起で保留した札は通常ドローに追加する案。情熱・疲労は通常ドローにだけ作用し、想起札の受け取り枚数を減らさない。

例：前ターンに2枚を想起し、通常ドローが疲労で2枚に減った場合、想起2枚＋通常2枚の計4枚を使える。通常ドローが0枚でも保留札は受け取れる。多数ドローとリスク回避の両方に役割を持たせられる。

現行PROは、次ターンの研修を経て行動開始時に通常ドローする。MASTERでは「次ターン開始時に想起札を手札へ → 研修 → 行動開始時に通常ドロー」の接続を提案する。研修中も想起札を手札から消さず、まだ通常配置できない状態で保持する。会議・通常返却では保留札を山札へ戻さない。

### 条件・枚数・対象選択

カード文面は「想起：山札の教務Rを最大1枚」のように、対象条件と上限枚数を書く。対象札の選択に択数制限は設けない。配置先から決まる固定の想起効果に従って対象札を選び、効果モードの宣言は要求しない。

対象条件にはカテゴリ、レア度、並行の有無、疲労の有無、選んだMRなどを使う。新カード案では、教務SR、応対N・R、並行Rまたは選んだMR、疲労を生むSR、教務・動員SSRなどを用意した。

条件に合う山札の実在札をすべて選択可能にし、候補の一部をランダムに隠さない。多い場合はカテゴリ・レア度で絞り込み、同名札をまとめて所持枚数を示す案。追加の表示方法は共通UI側へ接続する。

候補が1種類なら自動選択する案。複数枚の想起では、同じ個体を重複して取らず、上限枚数まで対象を選ぶ。対象条件と操作回数・保留枚数の強さを分けて検討する。

### 境界の処理案

| ケース | 提案 |
|---|---|
| 対象範囲 | 発動した瞬間の山札のみ。手札・通常配置・契約・研修候補・保留は対象外 |
| 同名札 | カードの種類と個体を区別。同名札が複数ある場合も実在する枚数まで取り置く |
| 対象が不足 | 「最大n枚」と表記し、ある分だけ想起。0枚なら対象なしと表示し、他の効果は通常処理 |
| 複数の想起 | 発動順に山札から取り出す。先に保留した個体を次の想起で二重に引かない |
| 条件の維持 | 検索時に判定する。取り置いた後に状況が変わっても、翌ターンに検索し直さない |
| 想起札の削除 | 保留中は会議の通常削除対象に含めない案。個体の所在を明示する |
| 最終ターン | 翌ターンがなく手札化しないことを表示。他の即時効果を併記する設計で不発を緩和する |
| 保留と得点 | 保留札も所持札に含め、通常使用・契約発動には数えない |
| 中断再開 | 対象個体・発動元・受け取るターン・選択の途中状態を保存し、二重検索・受け取りを防ぐ |

想起を解決する際にプレイヤーの対象選択が必要になれば、その時点で処理を止めて選択を受け、確定結果を保存してから後続カードを解決する案。スキップで対象を勝手に決めない。自動選択を採用した場合はこの停止を省く。

物語上は「教材や対応履歴を思い出し、翌回に使う準備を済ませる」。現在の行動で準備するので、今引ける札だけを先に取り置き、実行は翌ターンになる。

## 6. 膨張編成とデメリット回避

膨張編成は発想による取得、情熱・想起による手札、並行による配置をつなぐ。終盤の「通常スタッフに合計4枚以上配置」などを完成札の条件にする案。契約札は通常配置枚数に含めず、所持枚数、累計取得枚数、通常配置枚数、実使用枚数を分ける。

デメリット回避は、契約・先に解決する通常札による軽減、ステータス条件の回避、想起による必要札の確保を組み合わせる。

- 軽減する種類と量はカードに固定する。対象選択で軽減先を宣言しない。
- 疲労軽減はそのターンに発生する疲労、経理・満足軽減はそのターンの減少に、発動順で自動適用する案。前ターンからある疲労の消去とは区別する。
- 軽減後にコスト不足を判定する。無効なカードで軽減枠を消費しない案。細部は共通の効果解決と接続して確定する。
- 一つの継続効果で全デメリットを無制限に消す方式にはしない。
- 契約・MRの補助から後続の高リスク札へつなぐ。同時に契約2枚を使うコンボは、1枠案では成立しない。

回避できた負担、残った負担、実出力、翌ターンへの影響を記録する。想起による確定札が増えすぎて他のドロー手段を置き換えないかも比較する。

## 7. 既存カード維持と新規25案

## 8. 共通側に必要な接続とMASTERの表示

全難易度のUI・演出・評価は[共通改修計画](CdG-Shared-Work-Plan.md)側で扱う。MASTERからは次の要件を渡す。

| 接続点 | MASTERから伝える仕様 |
|---|---|
| 配置先 | 4つの配置先、契約の容量・指導制限・継続状態 |
| カード説明 | 通常効果と「契約：…」の別欄。「契約可」は不要。MR表示を追加 |
| 短縮表示 | 契約は「毎T 経+1」「配置4+：入+3」など。条件成立・指導中・不発の理由を示す |
| 想起 | 「教務Rを最大1／次T手札」の要約、保留札の種類・枚数・受取ターン |
| 所在 | 契約・保留を通常山札や手札と分け、数枚の要約で表示。保留は配置先にしない |
| 解決 | 契約先行、想起の発動時検索、保留から手札へのターン開始処理 |
| スキップ | 想起の必要な選択は残し、表示の待ち時間を省く。結果や札の所在を変えない |
| 保存 | MR選択、契約と指導状態、保留個体、選択途中、各段階の処理済み状態 |
| 評価 | MR・契約・想起・軽減の実績と構築タグ。全難易度の共通指標へ追加 |

長押し詳細とその目印、スマホ縦画面、通常速度の据え置きは既定方針。MASTERの契約効果は短縮表示でも通常効果との違いが分かる形にする。

## 9. 評価目標と記録項目

PRO比較のカード・ルール・戦略を固定し、MASTERの構築別に体験・入塾・満足・経理の平均・中央値・上下の分布を比較する。0〜35%は初期の代表値の目標案で、個々のゲームの値を35%で強制的に制限する仕様ではない。どの代表値を採用するかは未確定。

得点表の上限・退塾計算により、増分が得点に反映されない場合がある。MASTERの得点表・ランクはパラメータ分布を測ってから設計する。

約70%は事前に選んだ方針の構築成立率。MRを取れたことだけを成功とはしない。方針をプレイ後に分類し直して成功率を上げない。

| 方針 | 成立条件の初期候補 |
|---|---|
| 契約 | 序盤に契約し、3ターン以上有効に発動。対応する支援・完成札も機能 |
| 膨張 | 非基本の累計取得10枚以上、6枚以上の手札と4枚以上の通常配置を複数ターンで実現 |
| リスク回避 | 異なるデメリット札2種類以上を使い、軽減・条件回避・想起による準備が実際に寄与 |
| 想起 | 狙った核・支援・完成札を取り置き、翌ターンに受け取り、有効な行動・コンボに使用 |

成立率・成立ターン・得点分布を構築ごとに見る。未取得、引けない、配置不可、指導と競合、資源不足、条件不成立、上限、翌ターンがない、といった不成立理由を分ける。

| 対象 | MASTERで追加する指標 |
|---|---|
| MR | 選択率、初回手札化、実使用・有効発動、不発理由、支援・完成札への到達 |
| 契約 | 契約候補になった回数、通常使用／契約使用、契約ターン、指導役と休んだ行動、継続・有効発動・交代回数 |
| 契約の価値 | 残りターン別の実増分、軽減・想起などの後続価値、指導で失う通常行動との差、R／SR・条件別比較 |
| 想起 | 対象候補数、不足・0枚、保留枚数、受取枚数、受け取り後の使用、同じ札への集中、最終ターンの不発 |
| リスク | 負担の発生・軽減・残量、資源不足、契約自身の負担と後続札の負担 |
| 構築の幅 | 各MR・契約札の集中度、SRへの即時交代率、複数方針を組み合わせた実績 |

実測は共通評価基盤の接続後。乱数条件、コード・カード・ルール・戦略の版、試行数を併記し、契約の累積増分だけで通常使用より強いと判定しない。

## 10. 相談・設計・実装の順

当面は仕様計画のみ。相談順は次の案とする。

1. 想起と通常ドローの関係、対象不足と支払い、Nの契約可否を確定する。MRの契約不可と想起の択数制限なしは決定済み。
