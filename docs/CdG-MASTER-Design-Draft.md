## 1. 決定事項と、この文書の扱い

ユーザーが決定した内容は次のとおり。

- PROを土台に新難易度MASTERを制作する。
- 構築の幅を第一にし、狙ったカードやコンボを作りやすくする。
- 契約講師、膨張編成、デメリット回避の組み合わせ、デッキからの選択ドローを成立させる。
- 基本カードを含めカードプールは52種類以内。新カードは旧PROカードと入れ替える。
- カード取得は一度に3択以内、配置先は4択以内。配置後に効果の種類を宣言する選択は設けない。
- 序盤に役立つカードと終盤に強烈なコンボ効果を出すカードを両方収録する。
- 条件やリスクに応じ、各パラメータがPROより0〜35%程度高く出る設計を目指す。
- 望んだ構築の成立率は約70%。核が全く機能しない事態への対策を用意し、下振れは許容する。
- スマホ縦画面の圧縮表示、長押し詳細とその目印、速度据え置きでのタップスキップ、カード評価の見える化は全難易度共通に適用する。
- 今後の改善は作業ブランチで実施する。

**以下の具体的なルール、カード名、効果量、処理方式、成立条件はすべて提案。** 増加率・完成率はまだ測定していない。数値例は試作開始時のたたき台であり、目標達成済みの値ではない。

## 2. MASTERの基本構成案

PROの8ターン、基本カード5枠、初期ステータス、通常スタッフ3名、情熱・発想・整理・並行・疲労を出発点とする。

追加するのは、契約講師の常駐枠、序盤の核選択、構築を支える研修候補、選択ドロー、限定的なデメリット軽減。契約以外の通常配置先は室長・講師・事務で、合計4配置先以内とする。

カードを置いた後の効果は、配置先・配置済みの全カード・処理開始時の状態・既定の解決順から一意に決まる。「ドローするか得点を増やすか」といった効果モードの選択は追加しない。

4つの構築方針は組み合わせ可能とする。たとえば契約講師で疲労を軽減して膨張編成を支える構築や、選択ドローでデメリット回避の組み合わせをそろえる構築も評価する。

## 3. 契約講師の詳細案

### 配置と制限

| 項目 | 提案 |
|---|---|
| 枠数 | 契約講師は1枠、カードは1枚のみ。並行による重ね配置はできない |
| 配置できるカード | MASTERの「契約可」カードだけ。通常スタッフに置く場合と契約講師に置く場合の効果を、カードに固定して記載する |
| 雇用・交代のコスト | 契約講師に新しく配置・交代するターンは、通常の講師枠を使用できない。カードを配置する操作だけで適用する |
| 操作上の扱い | 講師枠に配置済みなら、新規契約・交代は配置不可と表示する。先に講師の配置を取り消すことはできる |
| 継続 | 行動を確定した後も契約カードは残り、次のターン以降も自動で効果を発揮する |
| 初回の効果 | 雇用したターンにも効果を発揮する。最後のターンで雇用しても、未来のドローだけの効果などは有効性が低いことを表示する |
| 交代 | 新しい契約カードを置く操作で交代する。旧カードは行動確定時に山札へ戻し、同じターンに再使用しない |
| 配置取消 | 行動確定前なら、新規配置・交代を取り消し、元の契約と講師枠の使用可否を復元できる |
| 自主退契 | 会議の削除機会を使って契約カードを除外する案。削除機会のないターンは交代で対応する |

雇用時に通常講師の行動を使うことで、早く契約して継続効果を得るか、そのターンの強い講師カードを使うかを判断できる。継続中のターンは講師枠を通常どおり使える。

### 自動解決と効果の強さ

- 行動確定時の解決順を、**契約講師 → 室長 → 講師 → 事務**とする案。
- 契約カードはターンに1回だけ解決する。効果が0増分でも、同じターンにもう一度解決しない。
- 契約に通常スタッフのおすすめ行動ボーナスは付けない案。繰り返す効果を小さく保つ。
- 継続効果は小さなステータス増分、疲労やコストの限定軽減、次ターンの選択ドローなどを中心にする。
- 契約可カードは通常スタッフにも固定の効果を持たせる。契約枠が使用中のときも、取得したカードを使う道を残す。
- 契約を任意のPROカードに適用する方式は採らず、専用に設計した効果だけを繰り返す。高打点SSRの無制限な再発動を防ぐ。

### カード領域と保存

契約カードは山札・手札・通常配置とは別の領域に保持する。所持枚数や最終所持カードには含めるが、通常ドローの候補には含めない。契約から山札へ戻った後は通常ドローの対象となる。

契約カードの個体ID、当ターンの解決済み状態、雇用・交代の途中状態、講師枠の制限、付与した補助効果を保存する。ターン終了時に通常配置を戻しても契約は維持し、再開・スキップでも同じ効果を二重適用しない。

## 4. 序盤の核と取得方法の案

### 初回研修：3択を2回

MASTERでは、PROの「4枚から2枚」を、次の2段階に置き換える案。初回取得の合計は2枚とする。

1. 固定のR核カード3枚から1枚を選ぶ。候補は「教務サポート契約」「チーム編成研修」「授業計画の共有」。
2. 選んだ核を支えるRカードを含む最大3候補から、もう1枚を選ぶ。

核3枚はそれぞれ契約・膨張・選択ドローの軸になる。リスク回避は契約や選択ドローに支援札を組み合わせて成立させる。4つの方針を4択のカード選択にする必要はない。

核選択はカードプール外の追加カードを作らず、MASTERの通常カード定義から取得する。選んだ核1枚は研修プールから消費し、選ばなかった核はプールに残す。

### 核が機能する機会を確保

- 最初の手札は、通常ドロー1枚を選んだ核に置換し、手札枚数を増やさずに核を含める案。
- 核は、低い条件で発揮できる基本効果を持つ。強い追加効果の条件が整っていなくても使えるようにする。
- 入塾上限などにより増分が0になる場合は、配置前の予測で分かるようにする。核の取得だけでなく、実際に効果が出た機会を記録する。
- 強い完成札の取得保証と、核の初回ドロー保証は別に扱う。約70%の構築成立を目標に、完成札の供給を調整する。

### 支援札・完成札の供給

2ターン目のSR研修と5ターン目のSSR研修に、核や初回の支援札に合う候補を1枠含め、残りを通常候補にする案。各研修のカード選択は最大3択。

適合はカード定義のタグで判定し、効果文の文字列検索で決めない。取得済みの核・支援札に応じて候補を自動で作り、追加の方針宣言を要求しない。

適合札の在庫が足りない場合の補充順、候補提示済みカードの扱い、同名2枚の供給、リフレッシュの対象は実装前に定義する。プールを無制限に複製して成立率を上げる方式にはしない。

## 5. 選択ドローの案

カードの固定効果「指名+1」で、**次の行動フェーズ開始時、通常ドロー1枚を選択ドローに置き換える**案。

- 効果解決時は指名の予約を付与するだけで、効果モードやカード対象を宣言する画面は出さない。
- 次のドロー工程で、山札から異なるカード名の最大3候補を提示し、1枚を選んで手札に移す。残りは山札に残す。
- 候補には、山札に残る核、取得済みの支援札・完成札、通常の候補を優先順位で含める案。契約中のカードや既に手札に移したカードは候補にしない。
- 候補が1枚なら自動で引く。2枚なら2択。候補の更新・移動結果を保存し、再開時に引き直さない。
- 複数予約時も各選択は3択以内。情熱・疲労適用後のドロー枚数を超えて置換しない。余剰予約の扱いと操作回数は実装前に決める。
- ドローを増やす情熱と、必要札へアクセスする指名を区別する。膨張と計画的な構築の組み合わせを評価する。

これは「配置時の選択効果宣言を設けない」と「カードを選んでドローしたい」を両立するための提案。山札全体から任意の1枚を選ぶ方式ではなく、最大3候補からの選択でよいかは相談事項とする。

## 6. 膨張編成とデメリット回避

### 膨張編成

多数取得は発想と適合候補、多数ドローは情熱、多数配置は並行で支える。手札が増えることを直接報酬にするより、取得・ドロー・配置が強い実効果に結び付くよう設計する。

終盤用のカードには「通常スタッフに合計4枚以上配置」などの条件付き増分を設ける案。配置枚数条件は確定した全配置で判定し、処理順によって条件が変わらないようにする。契約カードはこの通常配置枚数に含めない。

所持枚数、累計取得枚数、通常の配置枚数は区別する。カードを取得したが一度も使わない膨張と、ドロー・配置までつながった膨張を別々に測定する。

### デメリット回避

既存の疲労、経理減少、満足減少を活用し、配置先と解決順で組み合わせる案。

- 疲労軽減は、そのターンに獲得する疲労のうち指定数を自動で無効にする。契約講師や先に解決する通常カードで補助を用意する。
- 経理・満足の減少軽減は、そのターンの減少量に対して一定量まで適用する。全デメリットを恒常的に消す効果にはしない。
- 軽減する対象の種類と上限はカードに固定する。複数効果から軽減先を選ばせない。
- 軽減後の効果でコスト不足を判定する。カード全体が無効な場合は補助枠を消費しない案。条件・軽減・コスト確認・効果反映の順を本体とsolverで共有する。
- 回避できた疲労・減少量、回避できなかったデメリット、コンボ後の実出力を記録する。

たとえば疲労1を軽減する契約と、疲労1を軽減する並行カードを組み合わせ、疲労2を持つ高打点カードを使う構築を考えられる。実際の効果量はPRO比の出力を測定して調整する。

## 8. 全難易度共通のスマホUI・演出案

- 縦画面の上部にターン、主要ステータス、目標との差を圧縮表示する。
- 配置済みカードは名前と短縮効果を中心に表示し、スタッフ見出しや空白の繰り返しを減らす。MASTERの4枠は2列×2段を第一案とする。
- 並行でカードが増えても、配置順・条件成立・コスト不足・契約の継続状態を判別できる表示にする。
- 詳細があるカードに「長押し」または詳細アイコンの目印を常時表示する。長押しと、詳細アイコンのタップで全文を開ける案。
- 長押し後に配置・取消のタップが誤発動しないようにし、スクロール操作では長押しをキャンセルする。
- 手札も短縮効果と状態を示し、まず4枚・8枚・12枚のケースで判断材料を一望できるか検証する。さらに多い手札の表示は別ケースとして検証し、表示都合による手札上限はこの案では設けない。
- 基準端末・画面サイズは今後選ぶ。文字サイズを一律に小さくするだけで縦幅を詰める方式にはしない。
- 現在の標準演出速度を維持する。ターン開始表示、現在のカード演出、ランク変動表示をタップで先へ進められる案。
- スキップは表示待ちだけを省く。カード効果・契約効果・イベント効果・保存・次フェーズ遷移は通常時と同じ結果にする。
- 効果解決と表示シーケンスを分離し、タップ連打・再読み込み・中断再開を検証する。

通常の取得・配置操作と、演出を進めるタップの受付は分ける。演出終了時のタップが背面の確定操作へ伝わらないようにする。

## 9. 目標の測定方法案

### PRO比0〜35%程度

比較用のPROカード・ルール・戦略を固定し、MASTERの構築別に最終の体験・入塾・満足・経理を測定する。各パラメータの平均・中央値・上振れ・下振れを併記する。

平均や中央値の比較を初期の設計指標とする案。個々のゲームの値をPRO比35%で強制的に制限する仕様にはしない。どの代表値・比較戦略を基準にするかは相談して確定する。比較元が0の場合は比率ではなく差分を表示する。

条件の軽い安定カードと、厳しい条件・リスクを持つカードの出力を分ける。構築に応じた強みを持たせ、すべての構築で全パラメータを最大化することは前提にしない。

PROの得点表の上限や退塾計算では、上昇したパラメータが得点に反映されない場合がある。MASTERの得点表・ランク閾値は、パラメータ分布を確認してから設計する。イベント専用の上限開放を、そのままMASTERへ適用することは決定していない。

### 望んだ構築の成立率約70%

試行開始時に目標の構築を固定し、プレイ後に別の構築へ分類し直して成功率を上げない。核の取得だけを成立とは数えず、支援札と実際の機能を含める。

成立条件の初期候補は次のとおり。測定開始前に基準を確定する。

| 方針 | 成立条件の候補 |
|---|---|
| 契約講師 | 序盤に契約が稼働し、3ターン以上有効に発動。対応する支援札または完成札も取得して機能している |
| 膨張 | 累計非基本カード取得10枚以上、6枚以上の手札と4枚以上の通常配置を複数ターンで実現している |
| リスク回避 | 異なるデメリット付きカードを2種類以上使い、補助効果や条件回避によるデメリット回避を実現している |
| 選択ドロー | 狙った核・支援・完成札を選択ドローで引き、実際にコンボまたは有効な行動につなげている |

構築ごとに試行数、成立率、成立ターン、核の実使用率、得点分布、不成立理由を表示する。全構築を合算した平均だけで約70%を判断しない。

核の不発は、未取得、引けない、配置できない、コスト不足、条件未成立、増分の上限、次ターン効果が間に合わない、といった原因に分けて確認する。

カード別の指標はFRESH・PRO・MASTERに共通適用する。MASTERではさらに契約の継続回数、雇用で失った講師行動、軽減量、選択ドローの実績を記録する。全難易度で乱数とカード・ルールの版を記録し、変更前後を比較する。

## 10. 実装前に確定したいことと着手順

優先して相談するのは、契約講師の雇用制限と、核3択・次ターン選択ドローの方式。次にカード入れ替え、成立条件、MASTERの得点を詰める。

実装順の案は、以下のとおり。

1. 既存の保存・進行・solverの不整合と、再現可能な検証基盤を整える。
2. 共有の効果解決を整え、全難易度のカード評価の基準値を記録する。
3. 共通UIの短縮表示・長押し目印・タップスキップを小さな単位で改善する。
4. MASTERの難易度分離・カード定義・初回研修・契約領域を試作する。
5. 選択ドロー・デメリット軽減・膨張条件を追加し、構築別の完成率と出力を測定する。
6. 52種類以内でカードを入れ替え・調整し、MASTERの得点とランクを定める。
