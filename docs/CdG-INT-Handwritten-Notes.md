## 講習期間ルール

- 使わなかったカードは次も手札に残る
- 毎ターン3枚ドロー
- 使ったカードは捨て札となり講習終了まで使えない
- 室長・講師にカードを配置しないと自動で「質問対応の基本」が配置される
- 毎ターン1枚以上 教務カードの配置が必須
