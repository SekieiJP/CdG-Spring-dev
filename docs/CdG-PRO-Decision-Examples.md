# PRO・リセマラなしの判断例（開発途中）

初期候補を選別せず、途中もリセットしない一発勝負の実例。最初に14点の例、後半に別の16点の例を示す。ブラウザで取得・配置・削除を判断して完走し、S+の14点になった。使った方略は取得・配置とも2ターン先読みで、同じ開発群250ゲームの平均12.244点、中央値12.5点、S+以上47/250。平均12.5点の目標と独立1000シードの完成確認は未達。

この1件は結果を見た後で選んだ判断例であり、各判断の因果的な優位や成功率を示さない。リセマラは15点狙いだけで利用できるが、本例では使っていない。ゲーム内の研修リフレッシュは利用可能。

## 入塾札を持っていても、毎回置く必要はない

第3ターンの手札にはNo47「プロジェクター授業」があった。開始値は体験9・入塾3・満足6・経理7。この回はNo40「ごほうび差し入れスイーツ」を室長、No36「締切間近の書類リマインド」を講師、No1「問合対応の基本」を事務に置いた。結果は体験13・入塾4・満足7・経理9、次回用の情熱2。

No47は第4・第5ターンに講師で使った。第5ターンは先に室長のNo7「元塾生に講習案内」で体験16→21としてから、No47で入塾14→21、経理12→11となった。入塾は体験を超えられないので、効果文の増加量だけで判断せず、実際に増やせる幅と経理コスト、他の配置を確認する。

この例のNo47が役立った事実と、旧方略の500局面比較でNo47の取得変更が平均を下げた結果は両立する。カードの一般的な強さや「第3ターンなら使わない」というルールにはしない。

## 回復してから、条件付きの並行札を重ねる

第5ターンの事務は、通常札No36を先に置き、並行札No13「休み時間トーク」、No49「卒業生からの手紙」の順に重ねた。

| 解決順 | 実際の変化 |
| --- | --- |
| No36 | 満足10→12、経理11→13、整理1 |
| No13 | 満足12→15 |
| No49 | 満足15以上の条件を満たし、情熱2・発想1 |

No49を満足12のまま先に解決すると情熱・発想は得られない。配置順はカードの解決時点の条件に合わせる。この順序規則は本体の実効果の検査でも確認した。取得した時点で条件未達でも、同じターンに満足を増やす札を先に使える場合がある。

## 最終ターンは、次回より今の得点を優先する

最終手札にはNo49とNo40もあったが、この回は配置しなかった。No7を室長、No24「苦手発見！質問対応」を講師、その後で並行のNo13・No30「最新入試情報リサーチ」2枚を講師、No38「未入金家庭へ電話」を事務に置いた。

No13は事務の満足増加ではなく、講師の体験2を使った。体験39→41として入塾の上限を確保し、No30を2枚解決して入塾34→37→40、満足31→33→35に到達した。最終値は体験41・入塾40・満足35・経理22、退塾0。動員4点・入退差7点・満足2点・退塾0の1点で合計14点。

将来用トークンを生む札にも、最終ターンは実得点へ換算できる効果が必要になる。上限や得点境界を確認して配置先を決める、という判断材料になる。

## 別の完走例：リセマラなしで16点

成長・削除研究のbaseline全250開始から、実際にSSの16点を取った1件を選んだ。開始はNo14「保護者面談」とNo7「元塾生に講習案内」で、初期候補・途中の展開をリセットしていない。この群の方略全体は平均11.996点、中央値12点、15点以上7/250、16点1/250。好例の1件を抜き出しても、方略全体の平均や成功率は変わらない。

### 条件を同じターンに作って、並行札を発動させる

第3ターンの開始は体験15・入塾0・満足13・経理7。取得したNo49「卒業生からの手紙」は、開始時点では満足15の条件を満たしていない。室長に通常札No3「質問対応の基本」、続けて並行のNo31「教室清掃」、No49の順に置いた。

No3で入塾0→2、No31で満足13→15・情熱1、続くNo49で情熱2・発想1が働いた。No14を講師、No2を事務で解決し、ターン後は体験20・入塾2・満足18・経理7、次回へ情熱3・発想1を残した。札を取る時点の条件だけでなく、同じターンの解決順で条件を作れるかが判断材料になる。

### 回復役を入れ替えてから基本札を削除する

No5「経理精算の基本」は、第2ターンに室長へ置いて経理5→7の回復に使った。第4ターンにNo16「備品注文」を取得し、事務で経理7→12へ回復してから、会議でNo5を削除した。

その後もNo16は第5・第8ターンに使われた。基本札を削除した事実だけを「基本札は不要」という攻略にせず、代わりの回復役と、実際に置く枠・引ける枚数を含めて検証する。この1件では削除そのものの優位までは分離していない。

### 最終手札から、体験・入塾・経理を同時に埋める

第8ターンの開始は体験43・入塾43・満足42・経理13。手札7枚から、次の5枚を置いた。

No16で経理15以上へ戻し、No21で体験50と入退差48の両方の境界へ届いた。最終値は体験50・入塾49・満足51・経理17・退塾0。本体の公式計算は動員5点・入退差8点・満足2点・退塾0の1点で16点だった。

満足は開始時点で35を超えていたが、No32には入塾を増やす役割もあった。一方、最後のNo31による満足49→51は加点の上積みにならない。最終取得のNo39「機材故障は本部に相談」は手札へ来ても配置しなかった。この成功例の取得・配置をすべて必須手順として扱わず、余剰効果や未使用札も記録し、取得の因果的な寄与は別の対照で確認する。
