# PRO・リセマラなしの判断例（開発途中）

初期候補を選別せず、途中もリセットしない一発勝負の実例。ブラウザで取得・配置・削除を判断して完走し、S+の14点になった。使った方略は取得・配置とも2ターン先読みで、同じ開発群250ゲームの平均12.244点、中央値12.5点、S+以上47/250。平均12.5点の目標と独立1000シードの完成確認は未達。

この1件は結果を見た後で選んだ判断例であり、各判断の因果的な優位や成功率を示さない。リセマラは15点狙いだけで利用できるが、本例では使っていない。ゲーム内の研修リフレッシュは利用可能。

## 入塾札を持っていても、毎回置く必要はない

第3ターンの手札にはNo47「プロジェクター授業」があった。開始値は体験9・入塾3・満足6・経理7。この回はNo40「ごほうび差し入れスイーツ」を塾長、No36「締切間近の書類リマインド」を講師、No1「問合対応の基本」を事務に置いた。結果は体験13・入塾4・満足7・経理9、次回用の情熱2。

No47は第4・第5ターンに講師で使った。第5ターンは先に塾長のNo7「元塾生に講習案内」で体験16→21としてから、No47で入塾14→21、経理12→11となった。入塾は体験を超えられないので、効果文の増加量だけで判断せず、実際に増やせる幅と経理コスト、他の配置を確認する。

この例のNo47が役立った事実と、旧方略の500局面比較でNo47の取得変更が平均を下げた結果は両立する。カードの一般的な強さや「第3ターンなら使わない」というルールにはしない。

## 回復してから、条件付きの並行札を重ねる

第5ターンの事務は、通常札No36を先に置き、並行札No13「休み時間トーク」、No49「卒業生からの手紙」の順に重ねた。

| 解決順 | 実際の変化 |
| --- | --- |
| No36 | 満足10→12、経理11→13、整理1 |
| No13 | 満足12→15 |
| No49 | 満足15以上の条件を満たし、情熱2・発想1 |

No49を満足12のまま先に解決すると情熱・発想は得られない。配置順はカードの解決時点の条件に合わせる。この順序規則は本体の実効果の検査でも確認した。取得した時点で条件未達でも、同じターンに満足を増やす札を先に使える場合がある。

## 最終ターンは、次回より今の得点を優先する

最終手札にはNo49とNo40もあったが、この回は配置しなかった。No7を塾長、No24「苦手発見！質問対応」を講師、その後で並行のNo13・No30「最新入試情報リサーチ」2枚を講師、No38「未入金家庭へ電話」を事務に置いた。

No13は事務の満足増加ではなく、講師の体験2を使った。体験39→41として入塾の上限を確保し、No30を2枚解決して入塾34→37→40、満足31→33→35に到達した。最終値は体験41・入塾40・満足35・経理22、退塾0。動員4点・入退差7点・満足2点・退塾0の1点で合計14点。

将来用トークンを生む札にも、最終ターンは実得点へ換算できる効果が必要になる。上限や得点境界を確認して配置先を決める、という判断材料になる。
