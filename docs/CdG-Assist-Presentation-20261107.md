# 選択枠と取得アシストの説明

2026-11-07。公開0058（main `564418fb56df3f5bb4a96f258d690a85b0d99587`）を基点に、`codex/assist-feedback` で改修する。修正ビルドは `v20260815-0059`（保存互換の上8桁を維持）。状態：実装・ローカル検証済み。

## 決定した表示

推奨かどうかと選択済みかどうかは別の情報として示す。未選択の推奨カードは細い黄色の輪郭と薄い黄色の光。選択した推奨カードは、**青い選択枠を輪郭より優先**し、黄色い光を残す。選択を解除したら黄色の輪郭へ戻す。取得前に選んでも、5秒後に推奨表示が始まった時点で青枠を保つ。カードの寸法は変えない。

長押しの取得アシスト説明は、提示開始時に固定したデッキ・数値・残りターン・推薦結果から作る。説明だけのために取得順位や数式の重みを変更しない。画面内の選択・解除では説明も変えず、リフレッシュ・発想の新候補で作り直す。設定オフ、推薦表示前、対象外モードでは表示しない。

`取得アシスト（比較評価）：…を評価しています` の形式は廃止する。説明は **🐤から始まる短い一文** にし、カード能力を別の言葉で並べ直さない。全文の効果・トークン解説は既存の詳細欄に残す。

| 対象・根拠 | 文例 |
|---|---|
| 初回に実際の体験供給を増やせる推薦 | 🐤序盤の体験づくりを助けてくれそうだ |
| 所有デッキの不足を、そのカード自身の効果で補える | 🐤いまのデッキで不足しそうな満足を補えそうだ |
| そのカードを使うと所持カードの条件を満たせる | 🐤満足が条件の所持カードと相性がいいね |
| 未達の条件を所有済みの供給で整えられる見込みがある | 🐤所持カードで満足を増やすと活かせそうだ |
| 入塾の効果に対して体験の空きが不足し、所持カード／同時取得で準備できる | 🐤体験を増やす所持カードと組み合わせられそうだ |
| 所持枚数がドローを上回り、今後の手数を補える | 🐤引きたい所持カードが多い今と相性がいいね |
| 配置先が混み合い、並行の有効な作用を一緒に使える | 🐤配置先が混み合う今のデッキと相性がいいね |
| 最優先の不足を補うカードがなく、推薦には別の有効な改善がある | 🐤今回は経理を補う選び方もアリ |
| 序盤から有効に使えて、残り日程とドロー率から複数回の使用を見込める | 🐤序盤から使えて、長く働いてくれそうだ |
| 最終ターンに有効な得点寄与が見込める | 🐤最後のターンの得点の上積みを狙えそうだ |

初回2枚の組み合わせ全体の理由を、片方のカードの能力として表示しない。各カード自身の作用を確認し、相方が必要な場合は「一緒に選ぶカード」として区別する。説明できる根拠がない場合は、曖昧な順位の断言や能力の列挙で埋めない。

## 非推奨カード

注意が要る点がなければ**何も表示せず、空欄の余白も作らない**。写真2の非推奨「教室清掃」のドロー・並行・満足の列挙は削除する。取得を否定する文言は出さない。

- 経理などの減少が実際に発動する配置では、`🐤経理を消費するので注意`。配置先で異なる場合はその前提を付ける。全ての配置で費用不足なら `🐤使う前に経理を増やしておこう`。
- 現在値より低い設定値に変わる場合だけ、設定値と使う順序への注意を示す。
- 疲労が情熱を上回り、次のターンがある場合だけ、次の手札が減ることを示す。最終ターンの疲労を将来の損として警告しない。
- 入塾が体験上限で十分に活きない場合は `🐤他のカードで体験を増やしてから使おう`。カード自身が先に体験を増やし入塾も活かせる場合は誤って警告しない。
- 有効な条件付き効果が現状では未達なら、`🐤いまは満足10以上の条件を満たしていないよ` のように現在の不足だけを示す。他の費用まで満たして使えるようになるという保証や、達成不能な数値調整の指示にはしない。現在は発動しない減少効果を、無条件の費用として扱わない。

## 実装と確認

説明生成は `acquisitionExplanation.js` に分離し、取得アシストの提示時に一度だけ生成する。本体と同じ条件・配置制限・コスト・効果順の適用器を使う。ゲームの反復試行、実際の未来順、乱数、結果は参照しない。根拠は表示用の内部コードで保持するが、その用語をプレイヤーへ見せない。

青枠と黄色い光の優先、選択前後と5秒の開始順、設定、長押し後の誤選択、再開時の固定、写真2相当の空欄、経理コスト・体験の準備・条件・残り日程・同時取得の区別を検証する。説明の見直しで既存の取得順位・ゲーム状態・乱数が変わらないことも確認する。

前回のCIはブラウザ447件で約19分を要したため、追加した表示テストを全て実行できるよう、ジョブの上限だけ20分から25分に拡張する。検査対象や再試行条件を緩める変更ではない。

新たな攻略の成績傾向を調べる変更ではないため、勝率・中央値の改善は主張しない。iPhone 12 SafariはWebKitのCI、スマートフォン表示は寸法エミュレーションでも検査し、実機PWA確認とは区別する。
