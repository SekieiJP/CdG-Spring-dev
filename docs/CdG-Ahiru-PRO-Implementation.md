# あひる先生・PRO実装の進捗

作業場所は `codex/ahiru-advice-ui`。2,000シード検証が動く `codex/ahiru-pro-strategy` とは別で、本体JSを変更しても検証側には影響しない。PROの表示と判定を本体へ接続した開発版。公開済み機能・達成済み方略・検証済みの予測精度とは扱わない。FRESH版はこの後に実装する。

## 実装した動作

- パラメータ欄の直後へ44pxの顔ボタンを置く。タップで、同じ行の吹き出しを開閉する。赤い汗顔、黄色の気づき顔、緑の笑顔と、改行なし25文字以内のセリフを共通表示部品へ渡す。操作画面では隠し、同じゲームの取得/削除へ戻ると開閉状態を引き継ぐ。再読み込み・新ゲームは閉じた状態から始める。
- 通常取得、初回2枚取得、発想の追加取得と辞退、会議の削除選択を公開状態だけから評価する。ゲームのカード、トークン、乱数、保存記録、選択には作用しない。会議表示時に計算した削除可能枚数を保持し、消費済み整理トークンを未来の価値として足さない。
- `ahiruProGoals.js` は公式PRO表から総合S得点と退塾なしの最小経路を作る。各パラメータのS表示だけでは11点となる状態と、総合12点へ届く経路を区別する。満足を伸ばす別経路も認め、全パラメータのS表示を一律に要求しない。
- `ahiruProForecast.js` は公開のパラメータ・所有札・トークン・日程だけを固定2回の式で投影する。初回2枚の選択は2枚とも決まってから反映する。削除は次ターンからを数え、最終会議は現在値で判断する。その場での反復シミュレーションはしない。
- 不足は満足/経理の回復役、総合Sへの不足、体験による入塾上限の順に確認する。カテゴリ名だけで回復役とせず、本体の効果解決器で条件・配置制限・コストを調べる。No40は経理の直接回復役ではなく、No50の経理14設定も15までの直接回復役には数えない。一方、公開日程の推奨ボーナスで補える場合は認める。
- 取得では伸ばす軸や手数の補強、削除では残す役を案内する。余剰の役を減らす案内は、該当札を除いた固定式も計算し、得点・満足/経理・回復手段を失わない場合に限る。選択した削除が得点を減らす時も注意する。削除できない会議で削除を勧めない。
- イベントでは公式の上限超過加点を含めて最終値を判断し、成長軸を通常モードの上限で余剰扱いしない。将来のイベントアイテム発動は投影に含めず、統計補正も使わない。計算機も統計補正を使わない。

## 暫定の補正と制限

`pro-projection-calibration.json` は、基準方略の開発250開始で計算した実際の最終値との差の中央値・分位値。選択前/後、時期、取得/削除を分け、250開始未満の削除時期を学習しない。足りない削除時期は次回取得前の補正を候補として使う。

補正を使うのは、カード・得点表の版、通常モード、観測したデッキ枚数範囲が合う時だけ。適用外は現在デッキだけの投影へ戻す。未取得の将来カードは現在デッキに含まれないため、投影には保守的な側面がある。分位値は共同確率や個別プレイの予測区間の保証ではない。独立データでの補正精度、セリフの適切さ、助言に従った人間の成績は未検証。

計算時間は各環境48状態で測り、95パーセンタイルはデスクトップ1.0ms、iPhone 12寸法1.7ms、Android寸法1.1ms。最大はそれぞれ2.0/3.6/2.2msだった。状態・乱数の不変も検査した。いずれもこのMac上のChromiumであり、iPhone 12 Safari実機の速度ではない。iPhone寸法の実画面画像を目視し、吹き出しがパラメータの直下に入り、候補や操作ボタンに重ならないことを確認した。実機Safariとホーム画面からの実起動は未確認。

詳細な実行記録は非追跡の `solver/local-runs/pro-mean125/ahiru-pro-ui-tests.json`。共通の表示部分を `solver/ui/` から `game/js/ahiruAdviceView.js` と `game/css/ahiru-advice.css` へ移し、独立表示試作の参照も更新した。既存の取得アシストの設定と5秒後のハイライトは維持している。

## 独立診断の準備

`solver/ahiru-advice-diagnostics.mjs <公開判断ディレクトリ> <出力JSON>` を追加した。補正を作った元開始との重複、公開入力・教師のハッシュ、全判断の対応、カード/得点表の版を先に照合する。独立データの検査では同じ開始の混入を拒否する。開発材料の接続確認にだけ `--development` で重複を許可し、出力にも明示する。4単体検査で、249開始・開始重複・局面/教師欠落・教師の取り違え・版違い・非有限値の拒否を確認した。

実際の助言と集計はブラウザ内。通常取得・発想取得・削除、選択前/後、各時期を分ける。同じ元ゲーム・時期内の総重みを1とし、250元開始未満の群には傾向を出さない。補正あり/なしの得点と各軸の誤差、軸別分位の被覆、表情の内訳を保存する。全開始の最終公開値でも公式得点を再確認し、最終会議のS判定が一致することを検査する。教師と私用seedは助言の入力に含めない。

この診断ツールは準備と入力検査まで。進行中の3研究ブラウザのうち1つが完了してから接続確認し、全2,000開始の完走・抽出後に独立診断を行う。学習250開始上の確認を独立精度の証拠にはしない。


## 全2,000開始での独立診断

補正作成の250開始とは重ならない全2,000開始から取得18,770・削除8,984の公開判断を抽出し、ブラウザ内で57,508回の助言を診断した。全最終値の公式得点と最終会議のS判定は2,000/2,000一致した。[予測と表情の全診断](../solver/research-results/ahiru-advice-20261103/pro-advice-validation.json)。

通常取得後の得点の平均絶対誤差は、第1ターンで補正なし8.553→補正あり4.928、第2ターン6.2025→1.7925と減った。一方、第6ターンは1.412→1.4905、第8ターンは0.7915→0.8135とわずかに悪化した。各時点の現在デッキだけの投影と、その後の取得を含む実際の最終値の比較であり、未来の結果を確実に予言するものではない。途中の助言の精度が完成したとは扱わない。

診断群の固定方略のS以上は68.75%。第8ターン取得後に緑となった28.8%のうち、S未達のゲームも全体の2.85%あった。反対に赤の後でも配置によってSへ届く。表情別の結果差を、助言に従うことの因果効果や人間の成功率には読み替えない。既存の補正係数はこの診断を見て再調整していない。

この全2,000開始の方略成績は平均12.0345・8点以下50回で不達成。最新の目標は1,000開始へ変更され、最初の1,000も8点以下26回で不達成だった。15指針の確定とFRESHの画面接続は引き続き未完了。
