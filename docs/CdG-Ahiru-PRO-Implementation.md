# あひる先生・PRO実装準備

作業場所はcodex/ahiru-advice-ui。2,000シード検証が動くcodex/ahiru-pro-strategyとは別で、本体JSを変更しても検証側には影響しない。現在の機能は未接続の準備段階で、PRO/FRESHアドバイスの完成ではない。

## ここまでの実装

- ahiruProGoals.jsは公式PRO表から総合S得点と退塾なしの最小経路を作る。各パラメータのS表示だけでは11点となる状態と、総合12点へ届く経路を区別する。S基準値を12と重複定義せず表から読む。
- ahiruProForecast.jsは公開のパラメータ・所有札・トークン・日程だけを固定2回の式で投影する。初回2枚の一部だけを選んだ段階では、選択済み全体の補正を先取りしない。削除場面では次ターンからを数え、整理を消費する。最終会議に未来の成長やトークンを足さない。
- pro-projection-calibration.jsonは、基準方略の開発250開始で計算した実際の最終値との差の中央値・分位値を保存する。選択前/後、時期、取得/削除を分け、250開始未満の削除時期を学習しない。足りない削除時期は次回取得前の補正を候補として使う。

補正を使うのは、カード・得点表の版、通常モード、観測したデッキ枚数範囲が合う時だけ。適用外は現在デッキだけの投影へ戻す。分位値は共同確率や個別プレイの予測区間の保証ではない。独立データで補正精度はまだ検証していない。

## 検査と未完了
