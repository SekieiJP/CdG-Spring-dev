# PRO・取得の得点差を学習する研究

2026-10-04。基本カード評価基盤の3ad4cf8から `codex/pro-paired-value-research` を分けた。目標はリセマラなし平均12.5点の方略完成と、その達成方略での全51カード評価。公開ゲーム・推薦・LEGEND、別作業場所で進行中の成分評価の8b24ad版は変更しない。

## 別の教師を使う理由

現在方略の公開状態から最終得点を学習し直すV5は、検証予測誤差が小さくなっても、実プレイの平均得点を明確に改善できなかった。今回は同じ公開研修から取得だけを変え、同じ継続シードと同じ後続方略で完走した2群の公式得点差を教師にする。得点の高い回に多く現れる札と、同じ局面で取得を変えて役立つ札を区別できるかを試す。

基準はその観測で実際に選ばれた取得、別条件は同じ観測でブラウザが計算済みの次順位の取得をコピーする。初回は2枚の組み合わせで、必ず1枚だけの入替とは限らない。カード単体の因果評価には使わず、取得選択全体の差として扱う。取得以降の実配置・削除・研修リフレッシュは現在基準V1/2ターン先読みのまま固定する。

## 固定した材料と実行

同じ8b24ad版・同じV1モデル・同じ設定で完走した3群、全750の異なる元ゲームを使用する。入塾比較baselineとV5比較baselineの計500開始を学習用、別の成分比較baseline250開始を検証用に先に固定した。全8配置局面、同じ本体/カード/得点表/方略、元順序で欠落なく全開始を採用し、リセマラ・途中打ち切り・学習検証の同じ開始を拒否した。

各元ゲームから1局面を、元の順番でT1/T3/T5/T7に巡回割当する。全750局面で188/188/187/187局面となり、各時期は250未満なので時期別の効果の傾向を主張しない。各カードの件数も保証していない。モデルの検証は別250の元ゲームで行い、カード別・相性別の結論は達成方略の本評価で改めて最低250開始を確保する。

[固定ソース](../solver/research-scenarios/pro-paired-value-sources.json)、[全開始・分離・版・局面集の監査](../solver/research-results/pro-mean125-20261004/paired-value-source-preparation.json)。実行用局面は公開状態だけを含み、元のシード・得点・未来順序を含まない。公開の提示/除外履歴から既知の研修使用枚数だけを復元する。継続用には別の新しい750シードを使い、2群で共通にする。判断へ実シードを渡さない。

全750局面×2条件、計1,500継続を結果で選別せず完走する。これは元の750ゲームからの対照で、1,500の独立開始から平均12.5点を検証するものではない。空いた2ブラウザ枠で実行し、成分評価を含む研究ブラウザを3つ以内に保つ。観測待ちの期限だけを理由にゲームを停止・再開しない。

## ブラウザで作る固定評価

公開の状態特徴102個と、別取得後−基準取得後の同じ特徴差102個、計204個を使う。現在値、トークン、残りターン、所持数、役割・レアリティ、固定投影、各カード枚数、公開履歴の既存特徴である。特徴に実シード・最終得点・非公開の並びを含めない。

公式得点の差はブラウザ内で教師にし、逆向きの組も教師の符号を反転し、各向き重み0.5で学習する。入力向きを反転した2予測の差の半分を出力し、「基準→別取得」の得点差が「別取得→基準」の負になることを保証する。状態が高得点になりやすいだけの加算を、取得の上積みとして使わない。

結果を見る前に、深さ2・120本・学習率0.05・8分割・特徴抽出0.75・行抽出0.8・最少葉25行/重み10・正則化5・固定乱数904125を指定する。学習・予測・特徴・検証の計算はブラウザ内。Nodeは起動と記録管理、公式得点のコピー、版/分離の検査だけに使う。

検証250局面で得点差の誤差をゼロ予測と比較し、全250を含めた選択変更の得点差も確認する。予測0点/0.15点を超えた時だけ別取得を採る条件を固定する。検証の中の少数の変更例だけから優位を主張しない。モデルを取得方略へ接続した後は、別の新しい各250開始で基準と比較し、予測誤差や局面継続だけで採用しない。平均12.5点の有望な版を固定後、調整に使わない独立1,000開始以上で到達を確認する。
