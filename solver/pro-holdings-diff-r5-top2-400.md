# PRO 所持カード分布差分析 (r5 top2 / 400eps)

対象データ: `solver/pro-tune-r5-top2-400.json`

- `pro_foundation`: S達成率 26.8%, A+率 38.8%, S+ 43件, 低得点 74件
- `pro_stable`: S達成率 26.8%, A+率 42.0%, S+ 60件, 低得点 49件

## 共通して確認できた差

- 低得点群では `生徒面談の基本 (N/応対)` が極端に高い。
  - foundation: S+ 23.3% / 低得点 94.6% (Δ -71.3pt)
  - stable: S+ 23.3% / 低得点 87.8% (Δ -64.4pt)
- S+群では `振込用紙印刷 (R/庶務)` の保持率が高い。
  - foundation: 62.8% / 40.5% (Δ +22.3pt)
  - stable: 68.3% / 36.7% (Δ +31.6pt)
- `今だけ！体験生特典 (SSR/動員)` もS+側で優位。
  - foundation: Δ +22.6pt
  - stable: Δ +18.3pt

## 方略別メモ

### pro_foundation

S+側に寄る:
- `今だけ！体験生特典`, `振込用紙印刷`, `保護者説明会`, `校門前ビラ配り`, `教室清掃`

低得点側に寄る:
- `生徒面談の基本`, `経理精算の基本`, `休み時間トーク`, `補習大会`, `プロジェクター授業`

### pro_stable

S+側に寄る:
- `振込用紙印刷`, `今だけ！体験生特典`, `備品注文`, `教室清掃`

低得点側に寄る:
- `生徒面談の基本`, `日々の出迎え`, `校門前ビラ配り`, `友人紹介`, `未入金家庭へ電話`, `日々の授業`

## 解釈

- N応対カードのデッキ残存が、低得点群の最も強い共通特徴。
- S+群は「経理を支えつつ入塾/動員を伸ばせるR〜SSRカード」に寄る。
- `pro_stable` は S達成率同等でA+率が高く、上振れより安定着地に強い。

## 次の調整候補

1. 会議削除で `生徒面談の基本` を最優先クラスに引き上げる。
2. 取得重みで `振込用紙印刷` / `今だけ！体験生特典` を微増。
3. `プロジェクター授業` は経理余力がない局面で評価を明確に下げる。
