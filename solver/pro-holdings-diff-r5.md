# PRO 所持カード分布差分析 (r5)

対象データ: `solver/pro-tune-r5.json`  
条件:
- 好成績群: **S+達成 (9点以上)**
- 悪成績群: **低得点 (0点以下)**

## 1. 全体傾向

- 3方略すべてで、悪成績群は `N` 比率が高い。
  - `pro_foundation`: Nシェア差 **-8.1pt** (S+ 37.4% / 低得点 45.5%)
  - `pro_stable`: Nシェア差 **-5.2pt** (41.6% / 46.8%)
  - `pro_upside`: Nシェア差 **-7.4pt** (38.9% / 46.3%)
- 逆にS+群では `R/SR/SSR` が相対的に増える（特に `SR`）。

## 2. 悪成績側に偏るカード

共通して悪成績群で過多:
- `生徒面談の基本 (N/応対)`
  - `pro_foundation`: **S+ 26.1% / 低得点 93.1%** (Δ -67.0pt)
  - `pro_stable`: **28.6% / 100.0%** (Δ -71.4pt)
  - `pro_upside`: **41.7% / 94.6%** (Δ -53.0pt)

追加で悪成績寄りになりやすいカード:
- `経理精算の基本 (N/庶務)`（foundation/upside）
- `プロジェクター授業 (SSR/教務)`（foundation/upside）
- `補習大会 (SR/教務)`（foundation/upside）

解釈:
- N応対の残存が多いと、満足の過剰獲得や打点不足の両方が起きやすい。
- 一部の高レア（例: `プロジェクター授業`）も、条件や他カードとの噛み合わせが悪いと低得点側へ寄る。

## 3. 好成績側に偏るカード

強くS+側に寄るカード（方略横断で目立つ）:
- `振込用紙印刷 (R/庶務)`
  - foundation: **S+ 78.3% / 低得点 27.6%** (Δ +50.7pt)
  - stable: **57.1% / 37.5%** (Δ +19.6pt)
  - upside: **66.7% / 41.1%** (Δ +25.6pt)
- `入塾手続きのご案内 (SR/庶務)`（stable/upsideで優位）
- `保護者説明会 (SR/動員)`（foundationで優位）
- `テレビCM放映 (SSR/動員)`（stableで優位）

解釈:
- S+群は「経理・入塾を同時に伸ばせる庶務/教務カード」の保持率が高い。
- 低得点群は応対過多で、入退差や動員の伸びに対するカード枠不足が見える。

## 4. 方略別メモ

- `pro_foundation` (S 31.7%, A+ 41.7%):
  - 分布差は最も明瞭。`振込用紙印刷` と `保護者説明会` の保持がS+群を押し上げる。
- `pro_stable` (S 28.3%, A+ 45.6%):
  - 安定寄りだが、悪成績側で `生徒面談の基本` 固着が強い。
- `pro_upside` (S 17.2%, A+ 28.9%):
  - 上振れ時はSR/SSR構成に寄る一方、下振れ時はN応対偏重へ戻りやすい。

## 5. 次の調整案

1. 会議削除で `N/応対`（特に `生徒面談の基本`）の削除優先をさらに上げる。
2. 研修評価で `振込用紙印刷` / `入塾手続きのご案内` / `保護者説明会` の優先度を少し上げる。
3. `プロジェクター授業` は単体評価を下げ、前提条件（経理余力/既存入塾）を満たす時のみ評価を上げる。
