# PROカードバランス提案 v2 (2026-04-18)

## 背景
- 直近solver観測（`pro_compress`）では A率は高い一方、S率(>=12pt)が低い。
- 代表値（r77/r79）
  - `exp40Rate`: 28-31%
  - `diff32Rate`: 29-31%
  - `exp50Rate`: 約3%
  - `diff40Rate`: 4-6%
  - `sClearRate`: 2.5-5.2%
- 結果として、A+帯(10-11点)から12点への押し上げが不足している。

## 観測されたボトルネック
1. 高閾値不足
- `体験40/50`, `入退差32/40` の到達率が低く、12点条件に届く終盤火力が不足。

2. 中位カードの期待値不足
- 使用頻度の割に平均点を押し下げるカードが存在（solver観測）
  - `褒めて励ます授業`
  - `できるまで居残り！`
  - `設問の急所は？教材研究`
  - `補習大会`

3. 特定カード依存
- `学力確認＆向上 公開模試` が実質的な主軸。
- 主軸を引けない試行で高閾値到達率が急落しやすい。

## バランス調整提案（PRO）
### A. 中位教務カードの底上げ（優先度: 高）
- `褒めて励ます授業`
  - 提案: 入塾+1 もしくは 体験+1 を追加（条件付きでも可）
- `できるまで居残り！`
  - 提案: 経理/満足のマイナスを緩和、または入塾寄与を+1
- `設問の急所は？教材研究`
  - 提案: 発想トークン量+1 または入塾増分+1

狙い: 模試以外の教務系でも `diff32` 到達ルートを作る。

### B. 動員40超えラインの補助（優先度: 高）
- `補習大会`, `元塾生に講習案内`, `チラシ折り` のいずれかに、
  - 体験増分の小幅上方（+1相当）
  - または終盤条件で体験上振れ効果

狙い: `exp40` を 30%台 -> 45%前後へ押し上げる。

### C. 庶務カードの役割分化（優先度: 中）
- `締切間近の書類リマインド` は「序盤の安全札」としては有効だが、
  終盤火力に繋がりにくい試行がある。
- 提案: 既存性能は維持しつつ、終盤に寄与する別庶務カードを小幅上方。
  - 例: `提出書類ファイリング` の入塾寄与 or トークン寄与を微増。

狙い: 安全確保だけで止まらず、12点到達へ接続する。

### D. 依存集中の緩和（優先度: 中）
- `学力確認＆向上 公開模試` 一強化はプレイ分岐を狭める。
- 提案: 模試の純弱体ではなく、代替SSR/SRの上方で分散。

## 調整後の検証目標
- `exp40Rate >= 45%`
- `diff32Rate >= 45%`
- `exp50Rate >= 10%` または `diff40Rate >= 12%`
- `S率(>=12pt) >= 10%`（短期）
- `S率(>=12pt) >= 25%`（当面目標）

## 備考
- 本提案は solver 観測＋人間ログ相関に基づくため、
  最終判断は実プレイテスト（人間/AI混在）での再検証が必要。
